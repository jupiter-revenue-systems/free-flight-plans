# Flight Plans: Hand Off Any Task

A Claude skill that turns any process into a step-by-step page with a copy button on every prompt and command. Anyone on your team can follow it.

## The promise

When you finish, you'll have one page for one real task that someone else can follow without messaging you.

## Who it's for

Coaches and agency owners whose team asks them how to do everything, and anyone who keeps re-explaining the same task.

## What's inside

- `skill/flight-plan/SKILL.md`: the skill. It interviews you, then builds the page.
- `skill/flight-plan/template.html`: the page design the skill fills in. One file, opens in any browser.
- `INSTALL.md`: how to add the skill in Claude.ai, Claude Cowork and Claude Code.

## How to use it

1. Install the skill with `INSTALL.md`.
2. Pick one task you've explained more than twice. Keep it under an hour.
3. In a new chat, say: `Make a flight plan for: [the task]. The person following it is: [who].`
4. Answer the questions one at a time. Paste in any old explanation you already wrote.
5. Save the HTML file Claude gives you, open it in your browser and click every copy button.
6. Hand it to someone who's never done the task and say nothing. Fix what they get stuck on.

## What it doesn't do

- It only knows what you tell it. A step you leave out stays out until a test catches it.
- It builds one process at a time. It doesn't map your whole business.
- It doesn't do the task. A person or an agent still follows the plan.
- It never puts passwords or keys on the page. It tells the reader where to get them.
